# 苏茧 · 补衣 — 设计说明

> 交付状态：`CARD-BUILT` + `CHECK-PASSED`（check_card.py：错误 0 / 警告 1 / 信息 1）
> 文件：`输出/苏茧 · 补衣.json`（39.5 KB，v3 JSON，纯文本卡）

---

## 一、核心命题

**她补的是衣服，收的是人不肯留下的那口气；而她自己身上那件，是唯一一件别人替她留的。**

一句话能复述，且能回答"她为什么会有这个"：殓房长大的孩子，把手艺当作替死人收口的仪式，所以对"衣料的来历"有近乎职业病的坚持。

## 二、三处设计决策

### 1. 一处怪：左手无名指缺一截

- 她给的解释是「剪刀咬的」。
- 但她的剪刀全是右手用的——回答与事实对不上，且她从不解释这个矛盾。
- 这符合 Taste Core 的"一处怪"：不是装饰性怪，是可被玩家抓住、却永远得不到完整答案的怪。

### 2. 一点危险：罩衣是双层内衬

- 她只穿自己做的衣服，**除了那件深灰蓝罩衣**。
- 内衬夹层缝着一方旧手帕。
- 世界书条目 4 设定为 `position=4 / depth=2` 的延迟触发条目——玩家不主动问，它不会浮出来。真相不在任何条目里，留给扮演现场。

### 3. 服装按真实结构分层

| 层 | 内容 | 结构说明 |
|---|---|---|
| 基础层 | 米白对襟中衣 | 棉麻，袖口翻两道边，针脚细到看不见 |
| 结构层 | 深灰蓝斜襟工作服 | 右襟压左襟；腋下两寸活口，抬手不勒；盘扣六缺二，用同色线缝死结 |
| 标志性延伸 | 腰后量衣尺 | 不是围裙带；布面磨白，刻度到三寸就没了——她自己剪的 |
| 配件系统 | 铜顶针、旧挑针 | 顶针凹痕深、取下来一圈白皮肤；挑针针尖磨短一半 |

**刻意避开**（对齐 `design-dislikes.md`）：无钟表、无链条、无蝴蝶玫瑰、无粒子；无"高级感补丁"式随机饰品；脖子、耳朵、手指全部空着。

## 三、信息分工表

| 信息 | 放在哪 | 为什么 |
|---|---|---|
| 外貌 / 服装结构 / 说话方式 / 行为边界 | `description` | 模型每轮都读，必须常驻 |
| 铺子陈设与街区规矩 | 世界书条 0（`constant=true`，`position=0`） | 场景底色，永远需要 |
| 殓房出身、收口本事、三不补 | 世界书条 1-3（`selective`，`position=1`） | 按话题触发，不占常驻预算 |
| 巷子、邻居、取件簿、价钱、器物 | 世界书条 5-9 | 世界厚度，玩家不问就不出现 |
| 罩衣内衬的破口 | 世界书条 4（`position=4`, `depth=2`） | 延迟触发，避免泄底 |
| 语气示范 | `mes_example`（4 段） | 靠示例学说话节奏，比形容词有效 |
| 玩法摩擦说明 | `creator_notes` | 只给玩家看，不进上下文 |

**没有一条世界书条目复述 `description`**——这是 `60-quality.md` 里 P0 级的硬伤（常驻字段复刻触发条目），本卡在构建时专门核对过。

## 四、开场白设计

按 `30-opening.md` 的两条硬判据自检：

- **前三行有拉力**：门轴响 + 湿石头味 + 红灯下的喜服 + 「打烊了」→ 反常（她在拆喜服，而她三不补里第一条就是不补喜服）。
- **最后三行可回**：她把目光停在玩家袖口，问「那件，穿多久了？」——玩家有明确可回的东西（衣服的来历），且这正是她的核心规矩（说来历才下针）。
- 全场没有替玩家写台词、动作、内心。玩家只被给了一个客观事实：袖口有道自己都没注意的口子。

## 五、技术选型

| 项 | 决策 | 理由 |
|---|---|---|
| MVU 变量 | **不用** | 这张卡靠对话推进，不靠数值；加变量会让玩家盯着状态栏而不是她 |
| 正则 / 状态栏 | **不用** | 同上。若要升级为 MVU 卡，见 `references/40-mvu-regex-ejs.md` |
| alternate_greetings | 2 条 | 一条深夜回访，一条白天取件，覆盖两种进入时机 |
| v3 PNG | **未打包** | 缺底图。给了底图就能 `build_card.py --image` 直接出 PNG |
